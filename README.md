# PLD

Project Light Diva is a fangame based on Project Diva and in particular on an already existing fangame named "PPD".
The objective of the project is to be able to play Project Diva charts on any device
Currently the game supports the following platforms :

- PSP
- PSVita
- iOS
- Android
- MacOS
- Linux
- Windows
- Web (Emscripten)
